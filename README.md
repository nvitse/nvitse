## Projets

### 🚧 Work in Progress

**Roccapina** <br>
Serveur auto-hébergé sur un VPS Debian : services Docker derrière Caddy et Authentik,
administration via Tailscale, sauvegardes chiffrées avec restic.

- **Coaching** : site d'entraînement sportif, une page par personne avec programme,
  suivi des séances et du poids.
- **Vault** : gestionnaire de mots de passe (Vaultwarden).

**MT5_Dashboard** <br>
Dashboard web local branché sur un terminal MT5 : serveur Python / FastAPI,
interface en JS, modules MQL5 homemade.

- **Desk** : graphiques avec VWAP, FVG, SMI et liquidité, sizing en R
  avec garde-fous sur le drawdown journalier.
- **Contexte** : calendrier macro, flux RSS policymakers, regime filter cross-asset.
- **Journal** : historique reconstitué depuis le terminal, statistiques
  et revue human-in-the-loop.

**Linux_Framework** <br>
Socle serveur reproductible : pré-installation de paquets, gestion des droits,
durcissement et logging, industrialisés en rôles Ansible.
<br>
Déploiement cible sur une infrastructure vSphere montée en labo : ESXi nested,
vCenter, puis chaîne Packer / Terraform / Ansible.
Documentation et code versionnés ensemble, décisions d'architecture incluses.

### 📦 Completed

**Boîte à outils** *(v1.1)*  
Scripts PowerShell maison pour l'administration Windows et le support MSP.
Automatisation des ops récurrentes du quotidien.

**On-Screen Keyboard (OSK)**  
Clavier virtuel flottant pour Firefox en mode kiosk : apparaît au focus d'un champ,
se déplace au doigt, disparaît au clic ailleurs.
Deux variantes de disposition : AZERTY et QWERTY.
